The CSV is an edge list — food,eater rows — the standard input for network analysis in R (igraph) or Python (networkx). Connectance is L/S², the directed convention. Trophic level is the longest-chain definition — a consumer is one above the highest thing it eats. The other standard definition is prey-averaged — one above the mean of its prey — and the two give different numbers for the same web, so a level of 4 here is not comparable to a prey-averaged 4 in a paper. Say which you used. More on reading a web in the field guide.
