## The incident, on the record

The 2026-08-19 session initially built these slices against a stale clone (`a4f3eba`, the
pre-sixth-pass base). Three things went wrong at once: the ADRs were numbered **ADR-023..026**,
colliding with the seventh pass's ADR-023..026 (2026-08-17); two of the four slices
re-implemented work that already existed on the real base (save-failure signaling — done
properly and additively by ADR-025/026 on 2026-08-17 — and the Workbench `.eco` import, done
by ADR-027 on 2026-08-18); and applying the batch clobbered eighth-pass versions of shared
files in the working copy. This correction restores the eighth-pass versions, renumbers the
two genuinely-new slices, and voids the stale remainder.
