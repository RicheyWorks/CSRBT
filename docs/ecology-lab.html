🌿 Ecology Field Day

Field-ecology instruments for students, TAs, and researchers — measure real field data, or a living data structure, with the same tools you'd take into the meadow: diversity indices, survivorship curves, quadrat dispersion, island turnover, Punnett squares, and more. Keys are species · touches are abundance · time is counted in operations. No install needed for the Workbench below — and everything prints clean for a lab report.
