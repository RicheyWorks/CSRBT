# ADR-116 — The third target: the science engine

**Status:** accepted · **Date:** 2026-09-01 · **Extends ADR-112/113; closes verify_engine_sessions' standing hole**

## 1. What the pages describe and no robot could run

The kit's pages describe experiments. `csrbt-experimental` runs them: the
classroom runner that parses an `.eco` protocol, drives it against a live
adaptive tree, grades its pre-registered hypotheses `CONFIRMED` / `REFUTED` /
`UNGRADEABLE`, computes its theory models and crosses, and renders the export
bundle; the strategy arena; the adaptive controller and its morph log; the
field day. Students run this from Gradle. After ADR-112 through 115 a robot
could drive every page and every organ of the organism — and not one
experiment. "Operate everything in the ecosystem" had a hole the size of the
science.

## 2. The decision

**`csrbt-lab`** is the third plugin, on the same gateway, policy, replay cache
and both transports, with nothing in any of them changed:

| piece | where |
|---|---|
| `LabConsole` | `csrbt-experimental/src/main/java/…/LabConsole.java` — stdin/stdout line protocol; a protocol crosses as one base64 token; no token, no policy |
| `:csrbt-experimental:harnessClasspath` | writes `build/harness/classpath.txt`, as WholeHog's task does |
| `LabPlugin` | `tools/harness_plugin_lab.py` — eight actions with declared risks |
| `--target lab`, `--target all` | both transports, through the shared builder |

| action | risk | what |
|---|---|---|
| `protocols` | READ | the shipped `.eco` files by name |
| `lint` | READ | parse only: what is declared, every malformed line named |
| `run-protocol` | NAVIGATE | a shipped protocol (enum), graded |
| `run` | NAVIGATE | any protocol (string, with a runnable example), graded: report, session, export names |
| `battle` | NAVIGATE | the arena: four strategies on a seeded workload (enum), ranked |
| `adapt` | NAVIGATE | the controller over a three-regime workload: the morph log, where it ended |
| `field-day` | NAVIGATE | the full-ecosystem survey |
| `export` | MUTATE | the bundle — CSVs, HTML, xlsx, pptx — written into scratch the plugin owns |

Compute that persists nothing is `NAVIGATE` — it moves an instrument and
changes no record — and is bounded (op caps in the schema, a 64 KiB protocol
cap). Nothing is `SENSITIVE_READ`: a protocol is the caller's own text and
every report is derived from it and a seeded workload. The one thing the
snapshot hides under the default policy is the last protocol's *name*,
because a name can be data.

**The one thing the harness refuses.** A protocol's `dwc:` line names a file
on disk for the runner to read. Through the harness that would be the harness
reading the operator's disk, which no target in this kit does — the page
plugin hands file inputs bytes from its own fixture table for the same
reason. The plugin refuses it before the console and the console refuses it
before parsing, so a client that reaches around the plugin is refused too.

## 3. The canonical oracle, and what it found

The strongest check available was already in the repository:
`docs/ecology-experiment-session.json` is the *shipped* output of the shipped
protocol, regenerated by the canonical Gradle task and dropped onto the
flagship page by students. `verify_lab` runs `sample-experiment` through the
gateway and requires the session it gets back to **equal the shipped file**.

It did not. `entered[*].quantity` — the Darwin Core quantity type the DwC
slice (ADR-107/108) added to every entered dataset — was in the engine's
output and not in the shipped artifact. The repository was the stale copy,
which is ADR-096's title, and the reason nobody had seen it is worth writing
down: `verify_engine_sessions`, the suite that binds shipped sessions to the
engine, had been `NOT VERIFIED` on every machine where it mattered, because
it hunted `~/.gradle` for a log4j jar that is never in the sandbox's cache.
An honest hole, reported honestly, for weeks — and a hole is not evidence.

Two fixes. The shipped session and `docs/experiment-out/session.json` are
regenerated by the canonical task (the text exports were byte-identical
already; the Office files are structure-pinned and were left as they were).
And `verify_engine_sessions` now reads the classpath
`:csrbt-experimental:harnessClasspath` writes — Gradle's own resolution,
log4j included — before falling back to the cache hunt. **It reports 26/26
for the first time**; the standing `ok--` in every `run_all` since ADR-108 is
gone.

## 4. Evidence

`tools/verify/verify_lab.py`, **35 checks**: risks and bounds; three plugins
in one manifest with distinct tool names; every lab tool formable by the
first robot's generator (ADR-114); the canonical oracle above, with six
confirmed and the one the protocol calls deliberately wrong refuted; a
hypothesis naming a phase that does not exist `UNGRADEABLE`, a malformed line
a named problem; `dwc:` refused at the boundary and at the console with no run
counted; the arena's four strategies ranked, deterministic in everything but
wall-clock time (and the rank time decides), different under a different
seed; the controller's morph log ordered and deterministic, starting
Red-Black and ending where its last morph says; the field day parsing into
its stations; export refused under the default policy, then writing the
bundle into the plugin's scratch with the session equal to the run's; the
name hidden unless `SENSITIVE_READ`; `--target lab` over stdio.

`tools/mutate_lab.py`: **nine mutants, nine killed, one equivalent.** The
first run killed *none* — every mutant "survived" in nine seconds. The copied
suite could not see `docs/`, so `run-protocol` raised, the suite crashed, and
a crash prints no `FAIL` line. The runner now reports a crashed suite as
`BAD MUTANT` rather than `SURVIVED` — and so do `mutate_organism` and
`mutate_mcp`, retroactively, because the same hole was in all three and had
simply never been hit. A tester that cannot tell "the suite found nothing"
from "the suite never ran" is the ADR-106 defect in the tester's tester.

`LabConsoleTest`, five tests in csrbt-experimental (256 green, javadoc clean).

## 5. Held

- **The arena's rank is not pinned**, on purpose: the composite score is half
  wall-clock time. The suite pins everything else (depth, rotations, hits,
  sizes) and says why. A rank that is reproducible would be a rank that is
  not measuring time.
- **`export` scratch is per-process.** A second `export` in one session lands
  in `export-2`; nothing is ever written outside the scratch, and nothing is
  cleaned up — an operator who wants the files has them, and an operator who
  wants them gone knows where they are.
- **The walker does not walk the lab.** Its cross-checks are the organism's.
  The lab's coverage is `verify_lab` plus the formability check; a lab walk
  would need its own general oracle (every `run` grades, every `battle` ranks
  four) and is a slice of its own.
