# ADR-030: Native xlsx/pptx in the experiment bundle — 2026-08-19

## Status

Accepted, implemented. Fires ADR-019 §2.6's held trigger (owner decision 2026-08-19):
the bundle's "Excel-ready CSV" and "PowerPoint-ready HTML" gain real native siblings —
`workbook.xlsx` and `report.pptx`.

## Context

ADR-019 held native Office output behind a named trigger to avoid a heavyweight
dependency before anyone asked for real files. The owner asked. The classroom reality
is that a student hands in a workbook and presents from a deck; "open the CSV in
Excel" is friction exactly where the seam is supposed to remove it.

## Decision

1. **Dependency: Apache POI (`poi-ooxml` 5.5.1)** via `libs.versions.toml`, declared
   ONLY in `csrbt-experimental` at `implementation` scope — no POI type leaks into
   the module's API; csrbt-core stays dependency-clean. POI rides the published POM
   as a runtime dependency (accepted cost of real OOXML).
2. **`OfficeExport`** builds both files **derived verbatim from the text bundle** —
   nothing is recomputed: a workbook cell is exactly the CSV field (typed: a field
   that is exactly a plain decimal becomes a numeric cell — never guessed), a slide
   verdict is exactly the report's ✅/❌/⚠ wording. Workbook: one bold-headed sheet
   per logical CSV, in bundle order. Deck: title slide (spec identity line — keys,
   seed, window; never the wall clock), phases table, graded hypotheses, field
   notebook.
3. **Wiring**: `ExperimentLab.runWithAllExports` = every `runWithExports` entry
   UTF-8-encoded **byte-identical to before**, plus the two Office files; `main`
   writes the full bundle. The existing CSV/HTML/JSON byte-determinism pins are
   untouched.
4. **Determinism contract — structural, not byte.** OOXML zips carry wall-clock
   entry/docProps timestamps POI stamps itself, so the two native files are NOT
   byte-pinned. What `OfficeExportTest` pins instead: running the same spec twice
   yields identical sheet names, cell types and values, and identical slide count
   and slide text. This is the strongest honest pin available without forging
   timestamps.

## Consequences

- `docs/experiment-out/` now carries the checked-in `workbook.xlsx`/`report.pptx`
  regenerated by `./gradlew ecologyExperiment`; expect their *bytes* to differ per
  regeneration while their *content* stays fixed — reviewers diff the CSVs, not the
  zips.
- csrbt-experimental's dependency footprint grows substantially (POI pulls XMLBeans
  et al.). Deliberate, module-scoped, and reversible if Central weight ever matters.
- ADR-019's export table should now read: CSV (byte-pinned) → Excel-native
  (structure-pinned); HTML (byte-pinned) → PowerPoint-native (structure-pinned).
